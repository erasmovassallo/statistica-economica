# Statistica Economica con R, Python e SAS

Edizione online ampliata basata sul volume *Statistica Economica con R* (2018) di Erasmo Vassallo.  

Il sito propone contenuti in italiano e in inglese. Ogni esempio è sviluppato in **R**, **Python** e **SAS**. Codice e risultati R e Python sono verificati e riprodotti online, mentre il codice SAS è basato su una licenza proprietaria con installazione locale non riproducibile su GitHub; alcune istruzioni SAS potrebbero risultare differenti dalla versione SasOnDemand.

**Sito:** https://erasmovassallo.github.io/statistica-economica/

## Contenuto del Repository

```
- `it/` – pagine in italiano
- `chapters/` – pagine in inglese
- `data/` – file di dati usati negli esempi
- `images/` – immagini statiche
- `_quarto.yml` – configurazione del sito (Quarto)
```
